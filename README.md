# 🚀 JavaScript Algorithms Mastery
This repository is dedicated to mastering programming logic and problem-solving through JavaScript.

## 🎯 The Challenge: Core Logic Only
To build a strong foundation, I follow the **"Lego Principle"**: building every solution from scratch without relying on high-level abstractions.

### 🚫 Forbidden Methods:
- `filter()`, `reduce()`, `sort()`, `find()`, `map()`

### ✅ Allowed Tools:
- `for` / `while` loops
- `if/else` conditionals
- Basic Array methods: `push()`, `pop()`, `shift()`, `split()`, `slice()`, `join()`
